RECOMMENDED LAYERING APPROACH
==============================
Draw each character from back to front:
  1. Back hair (female)
  2. Outfit + shoulders
  3. Neck
  4. Face base (jaw shape + gender)
  5. Skin overlay (acne/blotch/clear/glow)
  6. Eyes + iris color
  7. Eyebrows
  8. Nose
  9. Mouth + lipstick
  10. Front hair
  11. Ears
  12. Eyelashes
  13. Accessories (earrings/glasses/chain/headphones)
  14. Botched overlays (stitches, graft bumps, droopy eye)

TECHNICAL NOTES
=================
- Sprites should be front-facing, shoulder-up portraits
- Transparent PNG format preferred
- Each sprite layer should align to a consistent canvas (e.g. 280x400)
- The game renders at pixel ratio so designs should be crisp at 2x scale
- Botched surgery overlays are rare — drawn only when a surgery failed
- Continuous stats (Frame, Height) are handled by scaling the base template
  rather than discrete sprites
